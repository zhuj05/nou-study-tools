📌【空大學生自製】學期成績與課業進度小幫手（免安裝・安全直達版）

💡 「看課請走校方網站直達最穩，不要拿平時成績開玩笑；算成績、記日程用這個免帳密工具最安全！」

很多同學在準備課業時最擔心平時成績出狀況：
在學校官方網頁上看課，就像「親自到櫃檯蓋章打卡」，瀏覽器會直接與學校伺服器即時確認進度；如果使用非官方的第三方 App 看課，手機只要退到背景、切換視窗或開啟省電模式，背景連線很容易被手機系統中斷，導致「影片看完了，但學校伺服器根本沒收到時數封包」，平時成績白白蒸發。

這款工具專為空大同學設計，免安裝、免填任何帳號密碼，幫大家把「校方正版學習平台入口」與「實用學業計算」整合在一起，手機點開就能直接用！

🔒 三大安心特點：

• 校方正版直達：常用網頁一鍵直通學校「數位學習平台」與「教務系統」，觀看時間直接在官方系統即時存檔，100% 準確同步不漏算！

• 免填帳密更省心：純前端試算與入口整合，無須輸入學號與密碼，完全零個資與帳號外洩疑慮。

• 免安裝零負擔：線上網頁工具，點開即用，不佔手機容量，完全免費。

⭐ 4 大核心功能（點上方下拉選單切換）：

• 學期平均計算：最多可算 7 科，填入學分數即可自動加權計算（沒修滿 7 科直接留空）。

• 單科分數試算：支援一般學期與暑修配分計算，提早掌握期末及格門檻。

• 考試／作業日程記錄：隨手記下繳交期限與考試日，支援一鍵匯出 TXT 或 Excel 檔！

• 常用校園官方連結：畫面下方一鍵直達空大首頁、數位學習平台、教務系統、視訊面授教室、出版中心、學習指導中心及行事曆。
