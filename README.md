# 🎓 空大學期成績與課業進度小幫手 (nou-study-tools)

> 💡 **「看課請走校方網站直達最穩，不要拿平時成績開玩笑；算成績、記日程用這個免帳密工具最安全！」**

一款專為國立空中大學（NOU）同學打造的**輕量、免安裝、零個資風險**的純前端線上輔助工具。點開即用，不佔用手機容量，無須下載任何 App！

🔗 **線上正式版網址**：[https://zhuj05.github.io/nou-study-tools/](https://zhuj05.github.io/nou-study-tools/)

---

## 🛡️ 為什麼需要這款工具？（四大安心保證）

在準備空大學業時，許多同學最擔憂平時成績與學習紀錄遺失：
- **官方直達最穩固**：在學校官方網頁上看課，瀏覽器會直接與學校伺服器進行 Heartbeat 心跳驗證；若使用未經授權的第三方 App 看課，手機只要退到背景、切換視窗或啟動省電模式，連線極易被系統中斷，導致「影片看完了，但學校伺服器漏掉時數」，平時成績白白損失。
- **免填帳密更安心**：本工具採純前端運算與靜態部署，絕不索取學號、密碼或個人隱私，零資安外洩風險。
- **免安裝零負擔**：透過 GitHub Pages 部署，支援電腦、平板與手機瀏覽器秒開，不佔儲存空間。
- **離線試算無延遲**：成績加權與日常日程全由本機端運算，無伺服器延遲或當機困擾。

---

## ⭐ 5 大核心功能介紹

透過頂部「功能選擇」下拉選單，即可快速切換以下專屬功能：

1. **學期平均計算**
   - 支援最多 7 門科目成績加權運算，填入成績與學分數即刻算出學期總平均與 GPA（4.3 制）。
   - 修幾科填幾科，未修科目直接留空即可。
2. **單科成績試算**
   - 支援「非暑修」（平時 30%、期中 30%、期末 40%）與「暑修」（平時 30%、期末 70%）配分計算。
   - 即時掌握期末考及格門檻與通過狀態。
3. **考試與作業日期紀錄**
   - 支援快速套用期中/期末考第 1~6 節考試時段，或線上測驗/作業報告截止時間（23:59）。
   - 提供單科獨立快速重置與表單清空功能。
   - 支援「一鍵複製到 LINE 筆記本」與「匯出 Excel/CSV 紀錄」，方便自我備忘或與同學交流。
4. **重要行事曆日程**
   - 內建學期核心日程與時程提醒（開學日、補退選、期中考、期末考、成績公布等）。
   - 水平按鈕快速切換查詢，關鍵日期不再遺漏。
5. **常用校園官方捷徑**
   - 底部折疊選單整合高頻校園入口：空大首頁、數位學習平台 (UU)、教務行政系統、視訊面授教室、出版中心、教務處、學習指導中心及行事曆。
